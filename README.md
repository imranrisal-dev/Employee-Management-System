# Employee Management System (EMS)

A lightweight, console-based **Employee Management System** built using Python. This application allows users to manage employee records seamlessly with persistent data storage.

## 🚀 Features
* **Create Record:** Add new employee details (ID, Name, Role, Salary, etc.).
* **Read Record:** View all existing employee details in a structured format.
* **Update Record:** Modify specific details of an employee using their unique ID.
* **Delete Record:** Remove an employee's data permanently from the system.
* **Data Persistence:** Automatically saves all employee records into a text file (`employees.txt`), ensuring data isn't lost when the application closes.

## 🛠️ Technologies Used
* **Language:** Python 3.x
* **Storage:** File Handling (Text-based Database)
